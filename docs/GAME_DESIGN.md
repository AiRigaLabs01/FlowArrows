# FlowArrows — Game Design

## Цель

Создать самостоятельную мобильную puzzle-игру с механикой освобождения направленных элементов с игрового поля. Проект не копирует уровни, графику, название, ресурсы или код существующих игр.

## Основной игровой цикл

1. На поле размещены направленные элементы (pieces).
2. Каждый piece имеет геометрию и направление выхода.
3. Игрок выбирает piece.
4. Если его траектория выхода свободна, piece покидает поле.
5. Его удаление освобождает пути другим pieces.
6. Уровень завершён, когда поле очищено.

## Режимы MVP

- Zen: без жизней и наказаний.
- Challenge: учитываются ошибки и эффективность решения.

## Требования MVP

- Android first.
- Godot 4.
- Полностью offline.
- Без рекламы и рекламных SDK.
- Без обязательной регистрации.
- Процедурная генерация уровней.
- Каждый сгенерированный уровень должен быть доказуемо решаемым.
- Undo.
- Hint.
- Локальное сохранение прогресса.
- Поддержка touch-интерфейса.

## Не входит в первый этап

- Backend.
- Аккаунты.
- Multiplayer.
- Monetization.
- Online leaderboards.

## Принцип генерации

Уровень рассматривается как граф зависимостей. Ребро A -> B означает, что A нельзя удалить до B. Генератор сначала создаёт допустимую последовательность/граф решения, затем строит геометрию поля, реализующую эти зависимости. Solver независимо проверяет полученный уровень.

## Сложность

Оценка сложности будет учитывать:

- количество pieces;
- глубину dependency graph;
- branching factor;
- число доступных ходов в каждом состоянии;
- количество ложных визуальных кандидатов;
- длину критической цепочки;
- необходимость планирования нескольких ходов вперёд.

## Базовые сущности

- Piece — игровой элемент и его направленная траектория.
- BoardState — текущее состояние поля.
- Move — удаление одного доступного Piece.
- DependencyGraph — логические зависимости.
- Solver — проверка решаемости и поиск решения.
- LevelGenerator — генерация кандидатов.
- DifficultyEstimator — оценка сложности.
- LevelValidator — финальная проверка инвариантов.
